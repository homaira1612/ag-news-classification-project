# Merge Conflict Notes

## What caused the conflict
The same line in README.md (the project Status line) was edited differently
on the `main` branch and the `proposal` branch at the same time.

## How it was resolved
The two versions were manually reviewed on GitHub's conflict editor and
combined into a single status line that reflects both the finalized proposal
and the fact that model results are still to come.

## Result
The `proposal` branch was successfully merged into `main` via Pull Request.
