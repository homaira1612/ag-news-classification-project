# AG News Classification Project

A simple Artificial Neural Network (ANN) for classifying news articles into
four categories (World, Sports, Business, Sci/Tech) using the AG News dataset.

## Description
This project explores whether headline and short-description text alone is
enough for a lightweight ANN to reliably categorize news articles.
