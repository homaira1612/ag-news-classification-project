# AG News Classification Project

An end-to-end machine learning project classifying news articles from the AG News dataset into four categories (World, Sports, Business, Sci/Tech) using TF-IDF feature extraction and classical machine learning models.

## Repository Structure & Deliverables
* [`paper.md`](paper.md) - Complete formal research paper (Abstract, Intro, Methodology, Results, Discussion, Conclusion, References).
* [`experiment.ipynb`](experiment.ipynb) - Jupyter notebook containing data preprocessing, model training, evaluation metrics, and visual outputs.
* [`presentation.md`](presentation.md) - 7-slide presentation deck covering the project summary.
* `accuracy_comparison.png` - Visual chart comparing model accuracy and F1-scores.
* `per_class_performance.png` - Visual chart breaking down per-class F1-scores.

## Results Summary
* **Logistic Regression:** 91.2% Accuracy | 0.91 F1-Score
* **Random Forest:** 88.5% Accuracy | 0.88 F1-Score
